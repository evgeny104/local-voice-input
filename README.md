# Local Voice Input

Локальный голосовой ввод для Windows: удерживаете Space 3 с, говорите —
текст оказывается в буфере обмена и вставляется через Ctrl+V.
Распознавание — Whisper на CPU, обработка текста — LM Studio. Без облаков.

## Что нужно

- Windows 10/11, микрофон, Python 3.11+
- ffmpeg (Whisper читает им WAV; подойдёт портативная сборка)
- LM Studio — опционально, но рекомендуется (см. ниже)

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt
```

Модель Whisper (small, ~460 МБ) скачается при первом запуске автоматически.

## Запуск

```bash
python main.py
```

Приложение сидит в трее у часов. Зажмите Space 3 с → скажите фразу → отпустите.
После «Готово» вставьте текст через Ctrl+V. Выход — правый клик по значку трея.

## LM Studio: зачем нужна и как настроить

Whisper выдаёт **сырой текст** — без пунктуации и заглавных букв, со словами-паразитами
(«эээ», «ну») и ошибками распознавания. LLM в LM Studio исправляет это, не меняя смысл.

Настройка (5 минут):

1. Установите [LM Studio](https://lmstudio.ai/) и скачайте небольшую модель —
   например **Qwen2.5-3B-Instruct**, формат GGUF, вариант **Q4_K_M** (~2 ГБ).
2. Вкладка **Local Server → Start Server** (порт 1234 — по умолчанию).
3. В окне приложения кнопка «Проверить соединение» покажет статус.

**Без LM Studio приложение тоже работает** — в буфер обмена попадает сырой текст Whisper
(fallback). Разница на примерах:

| Сырой текст Whisper | Вставка без LM Studio | Вставка с LM Studio |
|---|---|---|
| ну эээ привет это тест голосового ввода | ну эээ привет это тест голосового ввода | Привет, это тест голосового ввода. |
| завтра в десять утра встреча с ивановым | завтра в десять утра встреча с ивановым | Завтра в десять утра встреча с Ивановым. |

## Ярлык для запуска

1. Правый клик на рабочем столе → **Создать → Ярлык**.
2. В поле «Расположение объекта» вставьте одной строкой (подставьте путь к проекту):
   `<папка проекта>\.venv\Scripts\pythonw.exe <папка проекта>\main.py`
3. Имя: `Local Voice Input` → Готово.

Двойной клик по ярлыку запускает приложение (значок появляется в трее у часов).
`pythonw.exe` — тот же Python, но без чёрного окна консоли.
Для автозапуска с Windows перенесите ярлык в папку автозагрузки: Win+R → `shell:startup`.

## Структура

```
main.py            точка входа
voice_input/       пакет: запись, клавиша, Whisper, LLM, буфер, GUI, трей, сборка
tests/             поэтапные тесты разработки: python -m tests.test_stage4
docs/requirements.txt   исходное ТЗ
PROGRESS.md        дневник разработки по этапам
```

## Приватность

Аудио и текст никуда не отправляются: Whisper работает на вашем CPU, LLM — в локальном
LM Studio. Временные WAV удаляются сразу после распознавания.
