Задача: разработать локальное приложение для голосового ввода с использованием Whisper и LM Studio

Ты — Senior Python Developer. Необходимо разработать полноценное локальное приложение для голосового ввода текста по принципу Voice Typing / Whisper Desktop.

Главная цель: я нажимаю и удерживаю клавишу Space, приложение записывает мой голос, распознаёт речь через Whisper и возвращает готовый текст. Всё должно работать локально, без платных API и облачных сервисов.

1. Технологический стек

Используй следующие технологии:

- Python 3.11 или выше.
- OpenAI Whisper — локальная модель распознавания речи (ASR).
- LM Studio — локальный сервер LLM.
- OpenAI-compatible API LM Studio для взаимодействия с языковой моделью.
- sounddevice — запись аудио с микрофона.
- soundfile — сохранение аудиозаписи.
- pynput — глобальное отслеживание нажатия клавиш.
- PySide6 — графический интерфейс приложения.
- requests — взаимодействие с локальным API LM Studio.

Не используй платные API, OpenAI API или сторонние облачные сервисы.

2. Логика работы приложения

Необходимо реализовать следующий сценарий:

1. Приложение запускается и работает в фоновом режиме.
2. Пользователь нажимает и удерживает клавишу Space.
3. После удержания клавиши в течение 3 секунд начинается запись с микрофона.
4. Во время записи пользователь может говорить.
5. Приложение визуально показывает, что идёт запись.
6. Когда пользователь отпускает Space, запись останавливается.
7. Записанный аудиофайл передаётся локальной модели Whisper.
8. Whisper преобразует речь в текст.
9. Полученный текст передаётся в LM Studio.
10. LLM обрабатывает текст: исправляет пунктуацию, форматирование и очевидные ошибки распознавания, не меняя смысл сказанного.
11. Приложение получает окончательный текст.
12. Текст автоматически копируется в буфер обмена.
13. Пользователь может вставить его в любое приложение через Ctrl+V.

Важно: клавиша Space должна работать глобально, даже если окно приложения не находится в фокусе.

3. Логика клавиши Space

Реализуй обработчик клавиатуры со следующими условиями:

- При нажатии Space запускается таймер на 3 секунды.
- Если пользователь отпустил клавишу раньше, запись не начинается.
- Если пользователь удерживает клавишу 3 секунды, начинается запись.
- При отпускании Space запись прекращается.
- После остановки записи начинается обработка аудио.
- Повторное нажатие во время обработки должно игнорироваться.
- Необходимо исключить повторное срабатывание клавиши (key repeat).

4. Интеграция Whisper

Whisper должен работать полностью локально.

Используй официальный пакет:

"openai-whisper"

Предусмотри возможность выбора размера модели:

- tiny
- base
- small
- medium
- large

По умолчанию используй модель base.

Модель должна загружаться один раз при запуске приложения, а не при каждой записи.

Предусмотри русский и английский языки. Желательно реализовать автоматическое определение языка.

Whisper должен получать записанный аудиофайл и возвращать распознанный текст.

5. Интеграция с LM Studio

У меня уже установлена десктопная версия LM Studio и локальная LLM.

Необходимо использовать локальный сервер LM Studio.

Предусмотри подключение через OpenAI-compatible API:

"http://localhost:1234/v1"

Модель должна обрабатывать текст, полученный от Whisper.

Задача LLM:

- Исправлять пунктуацию.
- Исправлять очевидные ошибки распознавания.
- Удалять лишние слова-паразиты только там, где это не меняет смысл.
- Сохранять исходный смысл и стиль речи.
- Не добавлять информацию от себя.
- Не превращать обычную речь в официальный текст.
- Возвращать только итоговый текст без пояснений.

Если LM Studio не запущена или модель недоступна, приложение должно всё равно возвращать исходный текст Whisper.

6. Графический интерфейс

Создай простое и удобное окно на PySide6.

В интерфейсе должны быть:

- Индикатор состояния приложения.
- Статус «Ожидание».
- Статус «Удерживайте Space».
- Статус «Идёт запись».
- Статус «Распознавание речи».
- Статус «Обработка текста».
- Статус «Готово».
- Кнопка включения и отключения голосового ввода.

- Настройки микрофона.
- Настройки размера модели Whisper.
- Настройки подключения к LM Studio.

7. Запись аудио

Требования:

- Запись с микрофона компьютера.
- Частота дискретизации 16 000 Гц.
- Моно.
- Формат WAV.
- Запись должна быть стабильной, без потери фрагментов.
- Необходимо корректно обрабатывать отсутствие микрофона.
- Временные аудиофайлы должны удаляться после обработки.

8. Архитектура проекта

Не пиши всё в одном Python-файле.

Раздели приложение на логические модули:

- "main.py" — точка входа.
- "gui.py" — графический интерфейс.
- "audio_recorder.py" — запись аудио.
- "keyboard_handler.py" — обработка глобальной клавиши Space.
- "whisper_engine.py" — распознавание речи.
- "llm_processor.py" — взаимодействие с LM Studio.
- "clipboard.py" — работа с буфером обмена.
- "config.py" — настройки приложения.

Допускается изменение структуры, если есть технические причины.
